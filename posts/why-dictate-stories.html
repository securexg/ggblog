Why I Stopped Fighting Text Editors and Started Dictating Visual Stories

Most blogging platforms force a choice between clean writing and rich visuals. Owning a simple HTML folder gives you both.

Nov 27, 2026 3 min read By Gaurav

When you only write occasionally, the hardest part of publishing is rarely the idea itself. It is the friction between having a thought and getting it onto a page that actually looks good when someone opens the link.

Hosted editors like Medium are great for plain paragraphs, right up until you want a clean comparison table, custom callout cards, or full control over how images sit on the screen. Paste raw HTML there and it breaks. Paste a table and it flattens.

Speak the draft, shape the layout

Instead of staring at a blinking cursor, it is much faster to talk through the story out loud. Once the ideas are out, turning that transcript into structured sections, a readable table, and a couple of well-placed photos takes moments.

The rule for this space Every post lives as a plain HTML file in one folder, backed up to GitHub and served globally on Cloudflare Pages. No database, no CMS updates, and no lock-in.
Approach Tables & Custom Layout Setup & Storage Reader Experience
Medium No raw HTML or native tables Zero setup, stored on Medium Clean, but gated by member popups
Notion Native tables, HTML only in framed box Zero setup, stored in workspace Great for docs, feels like a wiki
GitHub + Cloudflare Pages Full HTML, CSS, tables, and visuals One folder, backed up forever Fast, ad-free, custom link

What comes next

This first post is a living template. Whenever there is a new story to share, all it takes is dictating the rough version, dropping in the right visuals, and pushing one update so the link goes live.
